# Jeffrey Sickoria | Analytics and applied AI portfolio

**[View the live portfolio](https://jeffsickoria.github.io/)**

Four projects that turn data into decisions. Start with a worked example, then explore the controls and supporting evidence.

| Project | What you can try |
| --- | --- |
| [Flight reliability](https://jeffsickoria.github.io/#airport) | Compare morning and evening options for Atlanta, browse departures across 23 airports, and see how the ranking performed against an airport-only baseline. |
| [Citi Bike ridership](https://jeffsickoria.github.io/#bike) | Investigate the January 26–27, 2026 ridership drop by station and rider group, then explore trends against historical and weather-adjusted baselines. |
| [Watt’s Next](https://jeffsickoria.github.io/#watts) | Change data-center load assumptions and compare three pilot counties. This is an NYU Stern team capstone. |
| [Paratus](https://jeffsickoria.github.io/#paratus) | Reveal a supported job match, an evidence gap, and a résumé bullet in a fictional worked example. The tab links to the full application. |
